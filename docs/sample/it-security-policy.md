# Acme Corp — IT Security Policy

**Effective:** February 1, 2026
**Owner:** IT Security
**Classification:** Internal

## 1. Passwords and Authentication

All employees must use a password manager and enable multi-factor authentication (MFA) on every company system. Passwords must be at least 14 characters long and unique per service. Shared credentials are strictly prohibited.

## 2. Device Security

Company laptops must have full-disk encryption enabled and must be locked whenever unattended. Operating system and security updates must be installed within 7 days of release. Personal devices used for work must be registered with IT and enrolled in mobile device management.

## 3. Phishing and Social Engineering

Employees must report suspected phishing emails to security@acme.example using the "Report Phish" button within 1 hour of receipt. Acme runs simulated phishing exercises quarterly; employees who fail two consecutive simulations must complete additional security training.

## 4. Data Handling

Customer data must only be processed in approved systems. Downloading customer data to local machines is prohibited without written approval from the Data Protection Officer. All data transfers outside the company network must use approved encrypted channels.

## 5. Incident Response

Any suspected security incident must be reported to IT Security within 24 hours. The incident response team will acknowledge the report within 4 business hours and provide an initial assessment within 1 business day.
